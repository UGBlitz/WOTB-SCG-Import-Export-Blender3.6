# World Of Tanks Blitz SCG Blender Plugin

A simple Blender 3.6 Plugin that can be used to edit `.scg` files found in World Of Tanks Blitz

## Blender plugin
Read about it [here](blender/README.md)

## AI Disclaimer
This project adds new features to an existing open-source plugin. These additions were developed with AI, but every change was manually reviewed and tested before being included.
